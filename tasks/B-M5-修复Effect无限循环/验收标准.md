# 验收标准

## Bug 修复要求

修复后必须解决以下所有问题：

1. **消除无限循环**：组件挂载后 useEffect 只执行预期次数（加载一次数据），不产生无限重渲染
2. **修复 queryParams 引用不稳定**：不应每次渲染都创建新的 `queryParams` 对象
3. **修复 fetchUsers 依赖**：`useCallback` 的依赖不应包含每次渲染都变化的引用类型
4. **避免 effect 闭环**：effect 中更新的状态不应是 effect 自身的依赖

## 验收条件

1. 组件挂载后，`fetchUsers` 只调用 **1 次**（严格模式下开发环境 2 次）
2. 切换 `filter` 下拉框时，重新请求数据（但只请求 1 次/每次切换）
3. 组件卸载时，清理正在进行的请求（使用 AbortController）
4. 页面不卡死，CPU 不持续飙升
5. `settings` theme 变更不影响数据请求

## 推荐修复方案

- 将 `queryParams` 用 `useMemo` 包裹，依赖 `filter` 的具体字段
- 或将 `fetchUsers` 的依赖改为原始值（`filter.role`, `filter.status`），而非整个对象
- 添加 `AbortController` 取消未完成的请求
- `settings` 的 effect 依赖改为 `settings.theme` 字符串而非整个对象

## 测试命令

```bash
npm test -- --testPathPattern=UserList
# 或用浏览器验证：打开 React DevTools Profiler，确认无连续重渲染
```
