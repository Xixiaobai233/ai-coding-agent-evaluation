# 验收标准

## 测试覆盖要求

### `createUser`

| 测试场景 | 做法 |
|---------|------|
| 创建成功 | mock db.query 返回 []，检查 db.execute 参数 |
| 用户名已存在 | mock db.query 返回 [{id:1}]，验证抛 "已存在" 错误 |
| 数据库错误 | mock db.query 抛出异常，验证错误被传播 |

### `getUserById`

| 测试场景 | 做法 |
|---------|------|
| 用户存在 | mock db.query 返回含用户数据的数组，验证返回 User 对象 |
| 用户不存在 | mock db.query 返回 []，验证返回 null |
| ID 为负数 | 按设计处理（返回 null 或抛错） |

### `getUserByUsername`

| 测试场景 | 做法 |
|---------|------|
| 存在 | 验证返回正确用户 |
| 不存在 | 验证返回 null |

### `addPoints`

| 测试场景 | 做法 |
|---------|------|
| 成功加分 | mock 两次查询和更新，验证返回加分后积分 |
| points <= 0 | 验证抛 "必须为正数" |
| 用户不存在 | mock 第二次查询返回 []，验证抛 "用户不存在" |

### `deductPoints`

| 测试场景 | 做法 |
|---------|------|
| 成功扣分 | 积分充足，验证返回扣减后积分 |
| 积分不足 | 用户积分 < 扣除积分，验证抛 "积分不足" |
| 用户不存在 | getUserById 返回 null，验证抛 "不存在" |
| points <= 0 | 验证抛 "必须为正数" |

## Mock 验证

- 每个测试验证 `db.query` / `db.execute` 被调用的次数和参数
- Mock 在 `beforeEach` 中重置，测试间隔离

## 测试命令

```bash
npx jest userRepository.test.ts --coverage
# 行覆盖率应 >= 90%
```
