# 验收标准

## Bug 修复要求

修复后必须解决以下所有问题：

### 问题 1：Append 不生效
- `AddItem` 调用后，调用方应看到追加后的结果
- 必须返回新的 slice（修改函数签名）
- 调用方应使用返回值更新原变量

### 问题 2：意外修改原数据
- `UpdateAll` 中修改元素，调用方可看到修改（这是正确的 slice 行为）
- 修复文档注释，说明这种行为的预期
- 新增 `UpdateAllCopy` 函数，如果需要不修改原数据，返回一个新 slice

### 问题 3：子切片数据共享
- `BatchProcess` 返回的批次不应与原始 `data` 共享底层数组
- 修改批次中的元素不应影响原始数据
- 每个批次应是独立副本

### 问题 4：数据安全导出
- `GetData` 应返回数据副本，防止外部修改内部状态
- 内部 `data` 应由 `DataStore` 完全控制

## 功能正确性

1. **Append 生效**：
   ```go
   nums := []int{1, 2, 3}
   nums = AddItem(nums, 4)
   // nums 应为 [1, 2, 3, 4]
   ```

2. **批次独立**：
   ```go
   data := []int{1, 2, 3, 4, 5, 6}
   batches := BatchProcess(data, 2)
   batches[0][0] = 999
   // data[0] 应保持为 1，不应被修改
   ```

3. **数据封装**：
   ```go
   ds := NewDataStore()
   data := ds.GetData()
   data[0] = 999
   // ds.data[0] 应保持为 1
   ```

4. **RemoveFirst 不泄漏**：
   ```go
   nums := []int{1, 2, 3, 4}
   result := RemoveFirst(nums)
   // result 应为 [2, 3, 4]
   // nums[0] 仍为 1
   ```
