# 验收标准

## 重构要求

### 必须实现的方法

1. **`iter_logs(file_pattern: str)`** — 生成器，逐行读取日志文件，yield 解析后的 dict
2. **`filter_by_level(logs, level)`** — 生成器，按级别过滤
3. **`filter_by_time_range(logs, start, end)`** — 生成器，按时间范围过滤
4. **`extract_errors(logs)`** — 生成器，提取错误信息
5. **`analyze(level, days)`** — 返回生成器，串联以上各步
6. **`peek(generator, count)`** — 预览前 N 条，不消费原生成器（使用 `itertools.tee`）

### 代码质量

- 不使用任何 `list.append` 收集全部数据（调试用的 `list()` 转换除外）
- 每个生成器函数不超过 15 行
- 支持链式调用：`processor.extract_errors(processor.filter_by_level(processor.iter_logs("*.log"), "ERROR"))`
- 内存占用与日志总量无关，只与单个日志条目大小有关

### 性能验证

以下代码不应导致 OOM：

```python
# 假设有 10GB 日志文件
processor = LogProcessor("/var/logs")
for error in processor.analyze(level="ERROR", days=1):
    print(error["message"][:100])  # 逐条处理，不积累
```
