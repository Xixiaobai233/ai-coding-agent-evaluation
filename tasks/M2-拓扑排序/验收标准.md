# 验收标准

## 功能正确性

1. 简单依赖链：`topologicalSort(3, [[0,1],[1,2]])` → `[0,1,2]`
2. 多分支：`topologicalSort(4, [[0,1],[0,2],[1,3],[2,3]])` → 0 在 1 和 2 之前，1 和 2 在 3 之前
3. 有环检测：`topologicalSort(3, [[0,1],[1,2],[2,0]])` → `[]`
4. 自环：`topologicalSort(2, [[0,0]])` → `[]`
5. 无依赖：`topologicalSort(3, [])` → 返回包含 0,1,2 的任意排列
6. 多个连通分量：`topologicalSort(5, [[0,1],[2,3]])` → 结果中 0<1 且 2<3
7. 大规模图：1000 节点线性链，不报错，结果长度 = 1000

## 实现要求

- 可以使用 Kahn 算法（BFS）或 DFS 后序遍历
- 必须正确检测环
- 时间复杂度 O(V + E)
