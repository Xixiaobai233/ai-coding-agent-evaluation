# 验收标准

## Bug 修复清单

修复后必须解决以下所有问题：

1. **死循环 bug**：当 target 比中间值大时，`left = mid` 可能导致死循环（例如搜索不存在的元素）
2. **错误边界**：修复后 left/right 更新应为 `mid + 1` 和 `mid - 1`
3. **整数溢出防范**：mid 计算应使用 `left + Math.floor((right - left) / 2)` 而非 `Math.floor((left + right) / 2)`

## 功能正确性

1. **中间元素**：`binarySearch([1,2,3,4,5], 3)` → `2`
2. **首元素**：`binarySearch([1,2,3,4,5], 1)` → `0`
3. **尾元素**：`binarySearch([1,2,3,4,5], 5)` → `4`
4. **不存在**：`binarySearch([1,2,3,4,5], 6)` → `-1`
5. **空数组**：`binarySearch([], 1)` → `-1`
6. **单元素存在**：`binarySearch([1], 1)` → `0`
7. **单元素不存在**：`binarySearch([1], 2)` → `-1`
8. **两个元素**：`binarySearch([1,3], 3)` → `1`
9. **重复元素**：`binarySearch([1,2,2,2,3], 2)` → 返回任意一个 2 的位置
10. **大数组**：长度为 100000 的数组，搜索最后一个元素，应在 50ms 内返回
