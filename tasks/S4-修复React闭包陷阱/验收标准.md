# 验收标准

## Bug 修复要求

必须选择以下方案之一修复，不得直接在依赖数组里加 `count`：

**方案 A：使用函数式更新**
```javascript
setCount(prevCount => prevCount + 1);
```

**方案 B：使用 useRef 保存最新值**
```javascript
const countRef = useRef(count);
countRef.current = count;
// interval 中读取 countRef.current
```

## 验收条件

1. 每秒自动 +1，控制台输出的 count 值始终与页面显示一致
2. 点击按钮手动 +1 后，定时器能继续从新值开始递增
3. 定时器只创建一次，不会重复创建/销毁
4. 不产生 ESLint 的 `react-hooks/exhaustive-deps` 警告（如果使用方案 A）
