# 验收标准

## 测试覆盖要求

### `formatMoney`

| 测试场景 | 输入 | 期望输出 |
|---------|------|---------|
| 正常金额 | 1990 | "19.90" |
| 零 | 0 | "0.00" |
| 负数 | -500 | "-5.00" |
| 角 | 1050 | "10.50" |
| 分 | 1001 | "10.01" |
| 大额 | 100000000 | "1000000.00" |
| undefined | undefined | 抛 Error |
| null | null | 抛 Error |
| NaN | NaN | 抛 Error |
| 字符串数字 | "1990" | 抛 Error（或按需设计） |

### `truncate`

| 测试场景 | 输入 | 期望输出 |
|---------|------|---------|
| 短字符串 | ("hello", 10) | "hello" |
| 刚好截断 | ("hello", 5) | "hello" |
| 超出截断 | ("hello world", 5) | "hello..." |
| 中文字符 | ("你好世界", 4) | "你..." (你=2, 好=2, 超出) |
| 空字符串 | ("", 5) | "" |
| 非字符串 | (123, 5) | "" |
| maxLength 为 0 | ("hello", 0) | "..." |

### `uniqueBy`

| 测试场景 | 输入 | 期望输出 |
|---------|------|---------|
| 基本去重 | ([{id:1},{id:1},{id:2}], 'id') | [{id:1},{id:2}] |
| 空数组 | ([], 'id') | [] |
| 非数组 | (null, 'id') | [] |
| 全部唯一 | ([{id:1},{id:2}], 'id') | [{id:1},{id:2}] |
| 保留第一个 | ([{id:1,name:'a'},{id:1,name:'b'}], 'id') | [{id:1,name:'a'}] |
