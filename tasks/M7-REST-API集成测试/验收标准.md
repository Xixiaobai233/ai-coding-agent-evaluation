# 验收标准

## 测试覆盖要求

### 认证测试

1. **注册**：POST `/api/auth/register` 返回 201 和用户信息
2. **重复注册**：相同用户名再次注册返回 409
3. **登录成功**：POST `/api/auth/login` 返回 200 和 token
4. **登录失败**：错误密码返回 401
5. **缺少字段**：注册/登录时缺少字段返回 400

### 任务 CRUD 测试

6. **无需认证**：未带 token 请求 `/api/todos` 返回 401
7. **创建任务**：POST `/api/todos` 返回 201 和创建的任务
8. **获取列表**：GET `/api/todos` 返回 200 和任务数组
9. **获取单个**：GET `/api/todos/:id` 返回 200
10. **更新任务**：PUT `/api/todos/:id` 返回 200 和更新后的数据
11. **删除任务**：DELETE `/api/todos/:id` 返回 204
12. **重复删除**：再次 DELETE 同 id 返回 404
13. **分页**：GET `/api/todos?page=1&limit=5` 返回正确的分页结果
14. **状态过滤**：GET `/api/todos?status=completed` 只返回 completed 任务
15. **完整生命周期**：创建 → 查询 → 更新 → 再查询确认 → 删除 → 查询确认删除

### 隔离要求

- 测试间互不依赖，每个测试独立创建所需数据
- 使用 `before`/`after` 钩子管理服务器启停
- 测试数据库使用独立库或内存数据库，不污染生产数据

## 测试命令

```bash
# 启动测试数据库后再运行
node --test api.test.js
```
