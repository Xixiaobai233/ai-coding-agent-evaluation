# 验收标准

## Bug 修复要求

修复后必须解决以下所有问题：

1. **浮点数精度误差**：`0.1 + 0.2` 应精确等于 `0.3`（在合理误差范围内）
2. **金额比较**：`isEqual` 方法应使用误差容忍（epsilon）比较，而非直接 `===`
3. **累计误差**：多次加法运算后结果应在合理精度范围内

## 功能正确性

1. **简单加法**：`cart.addItem(0.1, 1); cart.addItem(0.2, 1); cart.getTotal()` → `0.3`
2. **多项累计**：`[0.1, 0.2, 0.3].forEach(p => cart.addItem(p, 1))` → `0.6`
3. **金额比较**：`isEqual(0.1 + 0.2, 0.3)` → `true`
4. **折扣判断**：总金额恰好为 100 时，`applyDiscount()` 应正确触发
5. **整数金额**：整数的加减乘除不受影响
6. **保留两位小数**：所有金额输出应保留两位小数（如 `0.50` 而非 `0.5`）
7. **大量商品**：1000 件单价 `0.99` 的商品，总额应为 `990.00`

## 限制条件

1. **不得引入外部库**（如 decimal.js、bignumber.js 等）
2. **不得将所有数字转为分（整数）再计算**——必须在浮点数层面解决
