# 验收标准

## 重构要求

### 必须解决以下问题

1. **阻塞问题**：消除所有 `readFileSync` / `writeFileSync`，改用 `fs.promises`
2. **并发处理**：同时处理多个图片，通过 `concurrency` 参数控制并发数（默认 3）
3. **容错**：单个图片处理失败时（文件不存在、格式不支持等），其他图片正常处理
4. **返回值**：返回 Promise，resolve 一个包含成功和失败结果的对象

### 函数签名

```typescript
async processImages(
  inputPaths: string[],
  outputDir: string,
  options: {
    resize?: { width: number; height: number };
    grayscale?: boolean;
    quality?: number;
    concurrency?: number;
  },
  onProgress?: (completed: number, total: number) => void
): Promise<{
  successful: Array<{ input: string; output: string; size: number }>;
  failed: Array<{ input: string; error: string }>;
}>
```

### 功能验证

- 处理 10 张图片，相比同步版本总耗时显著减少（因并发）
- 混入一个不存在的路径，返回结果中 `failed` 数组包含该错误，`successful` 包含其他 9 张
- `getMetadata` 返回 Promise，调用者能拿到正确的 metadata
