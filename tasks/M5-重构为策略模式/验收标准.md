# 验收标准

## 重构要求

### 必须创建以下策略类

1. **`PercentageDiscount`** — 百分比折扣
2. **`FixedDiscount`** — 固定金额折扣
3. **`BuyOneGetOneDiscount`** — 买一送一
4. **`LoyaltyDiscount`** — 会员积分抵扣
5. **`SeasonalDiscount`** — 季节性促销
6. **`CouponDiscount`** — 优惠券
7. **`DiscountContext`** — 上下文，根据类型选择策略

### 设计要求

1. 所有策略类实现同一个接口（或基类），包含 `calculate(order)` 方法
2. `DiscountContext` 可以通过 `registerStrategy(type, strategy)` 注册新策略
3. 计算逻辑与之前的 `calculate` 方法完全一致
4. 如果使用 TypeScript，需定义清晰的 interface

### 功能保持

```javascript
const calculator = new DiscountContext();
// 计算结果必须和重构前完全一致
calculator.calculate(order, 'percentage');  // 与原方法相同
calculator.calculate(order, 'coupon');      // 与原方法相同
```
