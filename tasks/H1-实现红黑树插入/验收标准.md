# 验收标准

## 功能正确性

1. 基本插入：插入 5 个不同数字，中序遍历输出升序排列
2. 重复插入：插入相同 key 两次，树中不出现重复节点（或覆盖）
3. 顺序插入：插入 1..100，树保持平衡，中序遍历正确
4. 逆序插入：插入 100..1，树保持平衡，中序遍历正确
5. 搜索功能：存在的 key 返回 true，不存在的返回 false

## 红黑树性质验证

必须通过 `validate()` 检查：

1. **性质 1**：每个节点是 RED 或 BLACK
2. **性质 2**：根节点是 BLACK
3. **性质 4**：没有连续的红色节点（红色节点的子节点都是黑色）
4. **性质 5**：从根到所有叶子的黑色节点数量相同

## 性能要求

- 插入 n 个元素的时间复杂度 O(n log n)
- 树的高度不超过 2 * log₂(n+1)
