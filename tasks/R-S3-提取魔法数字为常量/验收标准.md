# 验收标准

## 必须提取的常量（至少包含以下，可自行补充）

### 运费相关
- `FREE_SHIPPING_THRESHOLD` = 5000（免运费门槛）
- `BASE_SHIPPING_COST` = 150（基础运费）
- `FREE_ITEM_LIMIT` = 3（免运费商品数量上限）
- `EXTRA_ITEM_SHIPPING_COST` = 50（超出部分的单件运费）

### 包装费相关
- `GIFT_WRAPPING_FEE` = 30（礼品包装费）
- `FRAGILE_PACKING_FEE` = 60（易碎品附加包装费）

### 税率相关
- `BUSINESS_TAX_RATE` = 0.05（企业税率）
- `CONSUMER_TAX_RATE` = 0.13（个人税率）

### 积分相关
- `POINTS_PER_UNIT` = 10（每单位积分）
- `POINTS_DIVISOR` = 100（积分计算除数）

### 大额订单折扣
- `BULK_DISCOUNT_THRESHOLD` = 20000（大额订单门槛）
- `BULK_DISCOUNT_RATE` = 0.05（大额折扣比例）
- `MAX_BULK_DISCOUNT` = 2000（大额折扣上限）

### 会员折扣
- `PREMIUM_MEMBER_YEARS` = 5（高级会员年限）
- `PREMIUM_MEMBER_DISCOUNT_RATE` = 0.97（高级会员折扣率）
- `REGULAR_MEMBER_YEARS` = 2（普通会员年限门槛）
- `REGULAR_MEMBER_DISCOUNT_RATE` = 0.98（普通会员折扣率）

## 代码质量

- 魔法数字为零：代码中没有未命名的数值字面量（0 和 1 除外）
- 常量按功能分组，组间有空行分隔
- 常量声明放在文件顶部或独立 `constants.js` 模块
- 重构后输入输出行为完全一致
