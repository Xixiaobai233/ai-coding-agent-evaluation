# 验收标准

## 功能正确性

1. 正常合并：`merge([1,2,3,0,0,0], 3, [2,5,6], 3)` → `[1,2,2,3,5,6]`
2. nums2 为空：`merge([1], 1, [], 0)` → `[1]`
3. nums1 为空：`merge([0], 0, [1], 1)` → `[1]`
4. 全部逆序：`merge([4,5,6,0,0,0], 3, [1,2,3], 3)` → `[1,2,3,4,5,6]`
5. 有重复元素：`merge([1,1,1,0,0], 3, [1,2], 2)` → `[1,1,1,1,2]`
6. 其中一个数组元素全部相同：`merge([2,2,2,0,0,0], 3, [2,2,2], 3)` → `[2,2,2,2,2,2]`
7. 负数处理：`merge([-3,-1,0,0,0,0], 3, [-2,1,2], 3)` → `[-3,-2,-1,0,1,2]`

## 性能要求

- 时间复杂度必须为 O(m + n)
- 空间复杂度必须为 O(1)（原地修改）

## 代码质量

- 使用双指针从后往前遍历
- 函数签名清晰，有必要的注释
- 导出函数以便测试

## 测试命令

```bash
node --test merge.test.js
```
