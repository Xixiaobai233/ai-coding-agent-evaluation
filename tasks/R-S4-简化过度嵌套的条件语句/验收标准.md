# 验收标准

## 重构要求

### 必须提取的辅助函数（或等价结构）

1. **`isAuthenticated(user)`** — 用户存在且激活
2. **`isAdmin(user)`** — 角色为 admin
3. **`isOwner(user, resource)`** — 用户是资源所有者
4. **`hasDirectPermission(user, resource, action)`** — 用户有指定权限
5. **`isRoleAllowed(resource, user)`** — 资源的 allowedRoles 包含用户角色
6. **`canDelete(user, resource)`** — 是否有删除权限

### 代码质量

- 没有超过 2 层的嵌套（`if` 内不套 `if`）
- 主函数作为一个"路由"，快速返回各种 false 情况
- 每个辅助函数职责单一，不超过 10 行
- 逻辑等价于原函数（对所有输入组合返回相同结果）

### 功能保持

```javascript
// 正向测试
canAccessResource({ id: 1, isActive: true, isBanned: false, role: 'admin' }, { isPublic: false }, 'delete')
// 期望: true

// 反向测试
canAccessResource(null, {}, 'read')
// 期望: false

// 被禁用户
canAccessResource({ id: 1, isActive: true, isBanned: true, role: 'admin' }, { isPublic: true }, 'read')
// 期望: false
```
