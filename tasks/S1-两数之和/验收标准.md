# 验收标准

## 功能正确性

1. 普通情况：`twoSum([2, 7, 11, 15], 9)` 返回 `[0, 1]`
2. 元素重复：`twoSum([3, 3], 6)` 返回 `[0, 1]`
3. 乱序匹配：`twoSum([3, 2, 4], 6)` 返回 `[1, 2]`
4. 无解情况：`twoSum([1, 2, 3], 7)` 返回 `[]`
5. 负数参与：`twoSum([-1, -2, -3, -4, -5], -8)` 返回 `[2, 4]`
6. 空数组：`twoSum([], 0)` 返回 `[]`
7. 单元素：`twoSum([1], 1)` 返回 `[]`

## 性能要求

- 不能使用暴力 O(n²) 的双层循环解法
- 必须达到 O(n) 时间复杂度
- 使用哈希表（Map 或 Object）实现

## 代码质量

- 函数签名清晰，有必要的类型注释
- 导出函数以便测试

## 测试命令

```bash
# 如果有测试文件
node --test twoSum.test.js

# 或直接运行验证脚本
node verify.js
```
