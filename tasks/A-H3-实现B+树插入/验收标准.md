# 验收标准

## 功能正确性

1. 基本插入与搜索：插入后 `Search` 返回 `true`
2. 不存在的 key：未插入的 key 返回 `false`
3. 叶子分裂：插入超过阶数-1 个元素，节点正确分裂
4. 内部节点分裂：继续插入导致内部节点满，内部节点正确分裂
5. 中序遍历：返回有序结果
6. 范围查询：正确返回范围内的所有 key（包含边界）
7. 重复插入：插入相同 key，树中不出现重复（或覆盖）
8. 顺序插入大量数据：插入 1..1000，中序遍历正确
9. 树高保持平衡：所有叶子节点在同一层

## 性能要求

- 插入时间复杂度 O(log_M n)
- 搜索时间复杂度 O(log_M n)
- 树始终保持平衡

## 实现要求

- 阶数 M >= 3
- 叶子节点和内部节点需要区分（不同类型或 isLeaf 标记）
- 叶子节点之间必须通过 next 指针链接
- 插入后检查节点是否满，满则分裂
- 分裂时正确将中间关键字提升到父节点

## 代码质量

- 代码结构清晰，节点类型定义明确
- 使用 Go 的命名规范
- 通过 `go vet` 检查
