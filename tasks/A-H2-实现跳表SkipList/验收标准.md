# 验收标准

## 功能正确性

1. 基本插入与搜索：`add(1)` 后 `search(1)` → `true`
2. 不存在则返回 false：`search(0)` → `false`（未插入）
3. 删除已存在的元素：`erase(1)` → `true`，之后 `search(1)` → `false`
4. 删除不存在的元素：`erase(0)` → `false`
5. 重复值处理：插入两次 1，erase 一次后 search(1) → `true`，erase 再次后 search(1) → `false`
6. 顺序插入：插入 1..100，搜索全部存在
7. 逆序插入：插入 100..1，搜索全部存在
8. 随机插入与删除：随机插入和删除 1000 次，不报错
9. 空跳表搜索与删除：空表时 search 返回 false，erase 返回 false
10. 大规模测试：插入 10000 个元素，全部搜索成功

## 性能要求

- 期望时间复杂度 O(log n)
- `add` 和 `erase` 后跳表依然保持有序
- 不能退化为 O(n) 链表（即必须有多层索引）

## 实现要求

- 使用**多级链表**结构
- 层数使用随机算法（抛硬币法，概率 p = 0.5）
- 使用哨兵节点（头节点）简化边界处理
- 最大层数建议 16 或 32
- 不能直接使用数组排序或 JavaScript Set/Map 作弊

## 代码质量

- 代码结构清晰，有必要的注释
- 节点类包含 value、next 数组（每层的下一节点指针）
- 导出类以便测试
