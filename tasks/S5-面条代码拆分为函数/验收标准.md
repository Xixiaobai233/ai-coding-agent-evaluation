# 验收标准

## 重构要求

### 必须拆分出以下函数（或类似结构）

1. **`calculateItemDiscount(item)`** — 按商品类别计算折扣后的价格
2. **`calculateMemberDiscount(price, memberLevel)`** — 按会员等级计算折扣
3. **`applyCoupon(total, couponCode)`** — 应用优惠券
4. **`calculateShipping(subtotal, itemsCount)`** — 计算运费
5. **`calculateTax(amount)`** — 计算税费
6. **`processOrder(input)`** — 主函数，协调以上函数

### 代码质量

- 每个函数不超过 20 行
- 消除所有魔法数字（提取为常量）
- 添加必要的 JSDoc 注释
- 有基本的错误处理（输入格式错误时抛出有意义异常）

### 功能保持

重构后 `processOrder` 的输入输出行为必须完全一致：

```javascript
// 输入
const input = JSON.stringify({
  user: { memberLevel: 'gold' },
  items: [
    { name: 'iPhone', price: 6999, category: 'electronics' },
    { name: 'T-Shirt', price: 199, category: 'clothing', season: 'summer' }
  ],
  couponCode: 'SAVE10'
});

// 输出必须和重构前一致
```
